What to look for

  1. :hover — visual change on pointer hover (links & buttons).
  2. :focus — keyboard focus (tab) state — important for accessibility.
  3. :active — while the control is being pressed.
  4. :nth-child() — style specific list items (striping / emphasis).

All states use color/background changes to make the differences obvious. Try keyboard Tab to see :focus.

# Assignment 6 — Responsive Blog Layout

Files:
- `index.html` — main HTML file for the responsive blog layout.
- `styles.css` — CSS implementing Grid-based layout with `grid-template-areas` and media queries.

To view locally:
1. Open `assignment6/index.html` in your browser.
2. Resize the browser to see the responsive behavior (sidebar moves below main content at <=800px).

Requirements covered:
- Header with title and nav links
- Sidebar with categories on the left (moves below main content on small screens)
- Main area with two side-by-side posts
- Footer with contact info
- `grid-template-areas` used for layout and responsive media query at 800px

URI Encoding Demonstration

Example with Special Characters

Original URL with special characters:
https://example.com/search?query=HTML & CSS

Properly encoded URL:
https://example.com/search?query=HTML%20%26%20CSS

More URI Encoding Examples

URL with spaces and special characters:

  • Original: https://example.com/search?query=web development & design
  • Encoded: https://example.com/search?query=web%20development%20%26%20design

Common URI Encoding Reference

Character Encoded Description
Space %20 Space character
& %26 Ampersand
? %3F Question mark
# %23 Hash/pound sign
% %25 Percent sign

Note: URI encoding (percent encoding) is essential for ensuring URLs work correctly when they contain special characters. The %20 specifically represents a space character in URI encoding.

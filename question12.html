HTML Entities Demonstration

This paragraph demonstrates various HTML entities:

Basic HTML Entities:
Less than symbol: <
Greater than symbol: >
Ampersand symbol: &
Double quote: "
Single quote (apostrophe): '

Special Symbol Entities:
Copyright symbol: ©
Trademark symbol: ™
Registered trademark symbol: ®

Example in context:
To display HTML tags like <div> & <span>, we use entities.
The company "Web Solutions™" © 2024 is registered ®.

HTML entities are essential for displaying special characters that have meaning in HTML markup.
